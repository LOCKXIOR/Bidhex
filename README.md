# Bidhex
It is just an "app" coded with python... It's only meant to convert decimal numbers into binary, hexadecimal or colors

## What makes him special ?
I personally needed colors for designing my PyQt5 windows stylesheets, and I thought to myself that I could just build something like that... to help myself
I recently learned recursivity, so I thought it could be great to apply it somewhere ! 

## What more about the codes ?
As you can see, some parts of the code are not used... and of course I know it... but it can really help ! (if I wanna do an update):
### In "Backend" (Transfo) : 
- the opérant_show method was meant to know exactly who is doing something on the app. As you can see it is not used anywhere ! (for now)
- in the method deci_color you can see a parameter named longueur_idéale with a default value of 6. It is here to make the user able to choose in how many digits he will have his color hex code, but it isn't used yet... there is room for improvements though !

### In "Frontend" (UI) : 
- a, b, longueur and largeur are just here to help me modify somethings without searching too much ( a/b for buttons and longuer/largeur for the window)
- the method get_nombre here is for now useless... but I think it may help to keep it (for future improvements)
